---

Items in Qpon represent the products, services, or SKUs from your catalog. Coupons and campaigns can be scoped to specific items so that discounts apply only to qualifying purchases. The `external_id` field bridges Qpon item records back to your own inventory system, allowing you to pass your product ID at redemption time without duplicating catalog data.

---

## Create Item

`POST /api/organizations/{organization_id}/items`

Registers a new item under the given organization.

### Path Parameters

<ParamField path="organization_id" type="string" required>
  UUID of the organization the item belongs to.
</ParamField>

### Request Body

<ParamField body="@entity" type="string" required>
  Must be exactly `"org.quicko.qpon.item"`. Identifies the payload type for the API.
</ParamField>

<ParamField body="name" type="string" required>
  Display name for the item (e.g. `"Premium Subscription"`, `"Blue Sneakers – Size 10"`).
</ParamField>

<ParamField body="external_id" type="string" required>
  Your catalog's own identifier for this product or SKU. Use this value as `external_item_id` when calling the Offers or Redemptions API.
</ParamField>

<ParamField body="description" type="string">
  Optional human-readable description of the item.
</ParamField>

<ParamField body="custom_fields" type="object">
  Free-form JSON object for storing any additional metadata you want to attach to the item (e.g. category tags, weight, colour).
</ParamField>

### Response Fields

<ResponseField name="message" type="string">
  Human-readable confirmation, e.g. `"Successfully created item"`.
</ResponseField>

<ResponseField name="result" type="object">
  <Expandable title="result">
    <ResponseField name="item_id" type="string">
      UUID assigned by Qpon to the newly created item.
    </ResponseField>
    <ResponseField name="name" type="string">
      Display name of the item.
    </ResponseField>
    <ResponseField name="description" type="string">
      Item description.
    </ResponseField>
    <ResponseField name="external_id" type="string">
      The external identifier you supplied, echoed back.
    </ResponseField>
    <ResponseField name="custom_fields" type="object">
      Any custom metadata attached to the item.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp of when the record was created.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      ISO 8601 timestamp of the most recent update.
    </ResponseField>
  </Expandable>
</ResponseField>

### Example

```bash
curl --request POST \
  --url https://your-qpon-host/api/organizations/ORG_ID/items \
  --header 'Content-Type: application/json' \
  --data '{
    "@entity": "org.quicko.qpon.item",
    "name": "Premium Subscription",
    "external_id": "sku_premium_monthly",
    "description": "Monthly premium plan with all features unlocked"
  }'
```

## Upsert Item

`PUT /api/organizations/{organization_id}/items/upsert`

Creates an item if no record with the given `external_id` exists; otherwise updates the existing record. This is the recommended way to keep your Qpon item catalog in sync with your product inventory without performing a lookup first.

### Path Parameters

<ParamField path="organization_id" type="string" required>
  UUID of the organization.
</ParamField>

### Request Body

<ParamField body="@entity" type="string" required>
  Must be `"org.quicko.qpon.item"`.
</ParamField>

<ParamField body="name" type="string" required>
  Display name for the item.
</ParamField>

<ParamField body="external_id" type="string" required>
  Acts as the upsert key — if an item with this `external_id` already exists in the organization, its record is updated rather than a duplicate being created.
</ParamField>

<ParamField body="description" type="string">
  Optional description of the item.
</ParamField>

<ParamField body="custom_fields" type="object">
  Free-form metadata object.
</ParamField>

### Response Fields

<ResponseField name="message" type="string">
  `"Successfully upserted item"`.
</ResponseField>

<ResponseField name="result" type="object">
  <Expandable title="result">
    <ResponseField name="item_id" type="string">
      UUID of the created or updated item.
    </ResponseField>
    <ResponseField name="name" type="string">
      Display name of the item.
    </ResponseField>
    <ResponseField name="external_id" type="string">
      The external identifier echoed back.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 creation timestamp.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      ISO 8601 last-updated timestamp.
    </ResponseField>
  </Expandable>
</ResponseField>

### Example

```bash
curl --request PUT \
  --url https://your-qpon-host/api/organizations/ORG_ID/items/upsert \
  --header 'Content-Type: application/json' \
  --data '{
    "@entity": "org.quicko.qpon.item",
    "name": "Premium Subscription",
    "external_id": "sku_premium_monthly",
    "description": "Monthly premium plan – updated pricing"
  }'
```

## Fetch Items

`GET /api/organizations/{organization_id}/items`

Returns a paginated list of items registered under the organization. Optionally filter by name or external identifier.

### Path Parameters

<ParamField path="organization_id" type="string" required>
  UUID of the organization.
</ParamField>

### Query Parameters

<ParamField query="name" type="string">
  Filter by item name (exact match).
</ParamField>

<ParamField query="external_id" type="string">
  Filter by your catalog's identifier for the item.
</ParamField>

<ParamField query="skip" type="integer">
  Number of records to skip for pagination. Defaults to `0`.
</ParamField>

<ParamField query="take" type="integer">
  Maximum number of records to return. Defaults to `10`.
</ParamField>

### Response Fields

<ResponseField name="message" type="string">
  `"Successfully fetched items"`.
</ResponseField>

<ResponseField name="result" type="array">
  Array of item objects. Each item contains the same fields as the Create Item response.
</ResponseField>

### Example

```bash
curl --request GET \
  --url 'https://your-qpon-host/api/organizations/ORG_ID/items?skip=0&take=20&external_id=sku_premium_monthly'
```

## Update Item

`PATCH /api/organizations/{organization_id}/items/{item_id}`

Partially updates an item record. Only fields included in the request body are changed; omitted fields retain their current values.

### Path Parameters

<ParamField path="organization_id" type="string" required>
  UUID of the organization.
</ParamField>

<ParamField path="item_id" type="string" required>
  UUID of the item to update.
</ParamField>

### Request Body

All fields are optional. Provide only the fields you want to change.

<ParamField body="@entity" type="string">
  Must be `"org.quicko.qpon.item"` when provided.
</ParamField>

<ParamField body="name" type="string">
  Updated display name.
</ParamField>

<ParamField body="description" type="string">
  Updated description.
</ParamField>

<ParamField body="external_id" type="string">
  Updated external identifier.
</ParamField>

<ParamField body="custom_fields" type="object">
  Updated custom metadata.
</ParamField>

### Response Fields

<ResponseField name="message" type="string">
  `"Successfully updated item"`.
</ResponseField>

<ResponseField name="result" type="object">
  The full updated item object (same shape as Fetch Item).
</ResponseField>

### Example

```bash
curl --request PATCH \
  --url https://your-qpon-host/api/organizations/ORG_ID/items/ITEM_ID \
  --header 'Content-Type: application/json' \
  --data '{
    "@entity": "org.quicko.qpon.item",
    "description": "Monthly premium plan – now with 2x storage"
  }'
```

## Delete Item

`DELETE /api/organizations/{organization_id}/items/{item_id}`

Permanently removes an item record from the organization. This action cannot be undone.

### Path Parameters

<ParamField path="organization_id" type="string" required>
  UUID of the organization.
</ParamField>

<ParamField path="item_id" type="string" required>
  UUID of the item to delete.
</ParamField>

### Response Fields

<ResponseField name="message" type="string">
  `"Successfully deleted item"`.
</ResponseField>

<ResponseField name="result" type="object">
  Details about the deleted record.
</ResponseField>

### Example

```bash
curl --request DELETE \
  --url https://your-qpon-host/api/organizations/ORG_ID/items/ITEM_ID
```

## Download Item Sales Report

`GET /api/organizations/{organization_id}/items/reports`

Streams a CSV file summarising redemption activity aggregated by item. The file is named `item_sales_report.csv` and is served with `Content-Type: text/csv`.

### Path Parameters

<ParamField path="organization_id" type="string" required>
  UUID of the organization.
</ParamField>

### Query Parameters

<ParamField query="from" type="string">
  Start date for the report window in `YYYY-MM-DD` format (inclusive).
</ParamField>

<ParamField query="to" type="string">
  End date for the report window in `YYYY-MM-DD` format (inclusive).
</ParamField>

### Response

Returns a binary CSV file download.

| Header | Value |
|---|---|
| `Content-Type` | `text/csv` |
| `Content-Disposition` | `attachment; filename=item_sales_report.csv` |

### Example

```bash
curl --request GET \
  --url 'https://your-qpon-host/api/organizations/ORG_ID/items/reports?from=2024-01-01&to=2024-03-31' \
  --output item_sales_report.csv
```
