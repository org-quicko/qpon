Qpon is an open-source, self-hosted coupon management platform built for e-commerce teams, SaaS products, and marketing engineers who need full control over their promotional workflows. Rather than depending on a third-party service, Qpon gives you a production-ready REST API, a built-in Angular dashboard, and a TypeScript client library — all running on your own infrastructure, backed by PostgreSQL.

## What is Qpon?

At its core, Qpon is a coupon framework: a structured system for creating discount rules, grouping them into campaigns, generating coupon codes for end users, and tracking every redemption. The platform is built on **NestJS** (backend), **PostgreSQL** (persistence via TypeORM), and **Angular** (frontend dashboard), and is distributed as a single Docker image that bundles both the API and the frontend.

Whether you're running a flash sale, a referral program, or a long-term loyalty scheme, Qpon provides the primitives to model it — without locking your data behind a SaaS vendor.

## Tech Stack

| Layer      | Technology                                            |
| ---------- | ----------------------------------------------------- |
| Backend    | [NestJS](https://nestjs.com/) (Node.js, TypeScript)   |
| Database   | [PostgreSQL 17](https://www.postgresql.org/)          |
| ORM        | [TypeORM](https://typeorm.io/)                        |
| Frontend   | [Angular](https://angular.dev/)                       |

| Permissions| [CASL](https://casl.js.org/) ability-based access control |
| Packaging  | Docker multi-stage build (Node 22 Alpine)             |

## Project Structure

```
qpon/
├── api/          # NestJS backend — REST API, auth, migrations, services
├── frontend/     # Angular dashboard — campaigns, coupons, redemptions UI
├── lib/
│   ├── core/         # @org-quicko/qpon-core — Qpon-specific TypeScript entities
│   ├── client/       # @org-quicko/qpon-client — TypeScript API client SDK
│   └── sheet-core/   # @org-quicko/qpon-sheet-core — spreadsheet export entities
├── common/       # Shared resources (ER diagrams, DB schema)
└── resources/    # Global assets (Postman collections)
```

- **`api/`** — The heart of the platform. Contains all NestJS modules, controllers, services, guards, and TypeORM migration files. Serves both the REST API under `/api` and the Angular static build on `/`.
- **`frontend/`** — The Angular single-page application used to manage organizations, campaigns, coupons, and view redemption reports.
- **`lib/core`** — Qpon-specific TypeScript entities (`@org-quicko/qpon-core`) shared across the API and client packages.
- **`lib/client`** — A typed HTTP client library that wraps Qpon's REST endpoints, designed to be imported directly into your application code.
- **`lib/sheet-core`** — Entity definitions used for structured data exports (CSV/XLSX) of coupon and redemption data.
